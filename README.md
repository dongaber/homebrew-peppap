# Homebrew tap for Peppap

[Peppap](https://github.com/dongaber/peppap): your dev status in the MacBook notch.

```sh
brew install --cask dongaber/peppap/peppap
```

The cask is updated automatically by the [Peppap release workflow](https://github.com/dongaber/peppap/blob/main/.github/workflows/release.yml) on every stable release.

Installed before Peppap 0.6.0, when the cask lived in the main repository? Point the tap here once:

```sh
brew tap --custom-remote dongaber/peppap https://github.com/dongaber/homebrew-peppap
```
